# 모아 · MOA

메모, 표, 도형과 원본 파일 바로가기를 배치하는 개인 업무 보드입니다.

## Windows 10/11에서 실행

1. 배포 ZIP을 **압축 해제**합니다.
2. 업데이트할 때는 기존 연결 도우미 창을 먼저 닫으세요. 새 폴더의 **모아 실행.cmd**를 더블클릭하면 브라우저가 열립니다. Windows에 기본 포함된 PowerShell 연결 도우미가 함께 실행됩니다. EXE 설치나 Node.js 설치는 필요하지 않습니다.
3. 연결 도우미 콘솔 창은 사용 중 열어 두세요. 종료는 Ctrl+C 또는 창 닫기입니다.
4. **파일 연결**로 원본 파일을 선택합니다. 카드 클릭은 PC 기본 프로그램에서 그 원본을 엽니다. 복사본을 내려받지 않습니다.
5. 드래그하려면 **연결 폴더**에서 원본이 들어 있는 폴더를 한 번 지정한 뒤 파일을 보드로 끌어 놓습니다. 하위 폴더도 찾으며 여러 폴더를 추가할 수 있습니다.

브라우저는 탐색기에서 끌어온 파일의 전체 경로를 숨깁니다. 연결 도우미는 사용자가 지정한 폴더 안에서 이름·크기·수정 시각이 일치하는 원본을 찾습니다. 후보가 여러 개이거나 없으면 임의로 연결하지 않으며, 파일 연결 버튼으로 원본을 직접 선택하도록 안내합니다. 대규모 폴더 전체보다 실제 업무 폴더를 지정하면 빠릅니다. 폴더의 심볼릭 링크와 정션은 따라가지 않습니다.

한글·Office 등 해당 파일을 여는 프로그램이 PC에 설치되어 있어야 합니다. 원본이 이동되거나 삭제되면 다시 연결하세요. 파일 내용은 외부 서버로 업로드하지 않습니다. 회사 정책으로 PowerShell이 차단된 PC에서는 연결 도우미 실행이 제한될 수 있습니다.

`모아.html`만 직접 열 수도 있습니다. 이때는 순수 브라우저 모드여서 파일 클릭은 미리보기이며 Windows 기본 프로그램 실행은 지원하지 않습니다. 지원하는 브라우저에서는 원본 핸들을 저장하고, 그렇지 않으면 사본을 보관한다고 표시합니다. PC 바로가기는 반드시 **모아 실행.cmd**로 실행하세요.

## 보드 편집

- 보드 위쪽의 큰 제목 영역을 제거했습니다. 작은 페이지 이름은 상단 경로에서 수정합니다.
- 각 페이지의 좌표 크기는 고정하며 화면 **가로폭에 맞춰 확대·축소**합니다. 긴 페이지는 세로로 스크롤합니다.
- 메모·텍스트·표·사각형·원·가로 및 세로 구분선을 삽입할 수 있습니다.
- 개체를 선택한 뒤 이동 손잡이나 크기 손잡이를 드래그하면 **20px 격자**에 맞춥니다. 회전된 개체와 보드 경계에서는 경계 유지가 우선됩니다.
- 회전 손잡이는 **15도 간격**, 선택 도구모음은 **각도 입력 및 90도 회전**을 지원합니다.
- 파일을 놓은 보드 위치에 바로가기가 추가됩니다. 눈 버튼과 마우스 올리기는 미리보기입니다.
- 표 셀과 행·열 편집, 색 변경, 복제·삭제, 새 페이지 추가 및 하단 숫자 페이지 이동을 지원합니다.

## 새 블록 추가 (v0.3)

- **체크박스**: 할 일을 입력하고 완료 상태를 체크합니다. 내용과 완료 상태가 자동 저장됩니다.
- **더 삽입 → 미디어**: 이미지·움직이는 GIF·영상 파일을 보드 안에 표시합니다. 미디어는 브라우저에 사본으로 보관하며 파일당 100MB까지 지원합니다. 원본 바로가기 연결과는 별도의 삽입 기능입니다. MP4(H.264), WebM을 권장하며 코덱에 따라 재생이 제한될 수 있습니다.
- **더 삽입 → 인터넷 링크**: 표시 이름과 http/https 주소를 입력하면 새 탭에서 여는 링크 카드가 생깁니다. 브라우저 주소를 끌어 놓아도 추가할 수 있습니다. 링크 수정은 개체 선택 도구모음에서 합니다.
- **더 삽입 → 달력**: 월 선택·이전/다음 달·오늘 이동을 지원합니다. 날짜를 누르면 일정이나 메모를 저장·삭제할 수 있습니다.
- **더 삽입 → 페이지 링크**: 대상 페이지와 표시 이름을 지정합니다. 카드를 누르면 해당 페이지로 이동합니다. 이름을 비워 두면 대상 페이지의 현재 이름을 표시합니다.

보드 위의 ‘자유롭게 배치하는 나의 보드’ 안내 줄은 제거해 보드 영역을 넓혔습니다.

Notion처럼 파일을 올리고 카드로 여는 흐름을 사용할 수 있습니다. 순수 HTML 화면은 문서 미리보기와 로컬 보관을 제공하고, 연결 도우미 화면은 카드 클릭 시 원본 경로를 Windows 기본 프로그램에 전달합니다. 서버 업로드나 계정 간 동기화는 제공하지 않습니다.

## 데이터 보관

연결 도우미는 이 PC의 `http://127.0.0.1:17843`에서만 동작합니다. 작업은 같은 주소를 여는 브라우저의 IndexedDB에 자동 저장됩니다. 원본 경로 및 연결 폴더는 `%LOCALAPPDATA%\MoaWeb\links.json`에 보관됩니다. 작업 데이터는 브라우저마다 다르며 사이트 데이터를 삭제하면 사라집니다. 기존 `file://` HTML 직접 실행의 저장 공간과 연결 도우미 주소의 저장 공간은 서로 다릅니다. 클라우드 동기화는 제공하지 않습니다.

연결 도우미는 루프백 주소만 사용하고 Host/Origin과 매 실행마다 만든 비밀 토큰을 검사합니다. 등록한 문서 ID만 읽거나 열 수 있으며 실행 파일·스크립트는 등록할 수 없습니다. 80MB 초과 파일은 미리보기 대신 기본 프로그램에서 여세요. 원본 파일 내용은 도우미에 저장하지 않습니다.

## 미리보기

이미지, PDF, 일반 텍스트, DOCX 본문, XLS/XLSX 셀, PPTX 슬라이드 텍스트와 HWPX 본문을 표시합니다. 원본 문서의 모든 서식·이미지·차트를 재현하지 않습니다. HWP/DOC/PPT는 미리보기가 제한되지만 원본 프로그램에서 열 수 있습니다.

## 개발 및 ZIP 생성

Node.js 22.12 이상이 필요합니다. 실행 사용자에게는 필요하지 않습니다.

```sh
npm ci
npm run dev
npm test
npm run test:e2e
npm run test:html
npm run package:html
```

`src/`를 수정한 뒤 `npm run package:html`로 단독 HTML과 버전별 ZIP을 함께 생성합니다. ZIP에는 HTML, Windows CMD/PowerShell 도우미, 한국어 안내 및 수정 가능한 소스를 포함하고 의존성 캐시·EXE는 제외합니다. ZIP CRC와 HTML 일치를 검증합니다. 수정본 ZIP은 연결된 GitHub 저장소에 올려 내려받을 수 있게 전달합니다.

`windows/Moa-Local.ps1`는 PowerShell 5.1 문법과 Windows Forms 파일/폴더 선택 창을 사용합니다. Linux PowerShell에서 HTTP 및 경로 연결을 검증할 수 있으나 Windows의 실제 파일 선택 창과 한글/Office 실행은 Windows PC에서 확인해야 합니다. 관리 Chromium의 `file://` 차단으로 HTML 직접 실행 검증은 네이티브 브리지 없는 Electron Chromium 창에서 수행합니다.

기존 Electron 개발 소스는 `desktop/`에 유지합니다. `npm run desktop`으로 개발할 수 있으며 사용자 요청 없이 EXE를 새로 만들지 않습니다.
