# 모아 · MOA

메모, 업무 문서와 아이디어를 자유롭게 배치하는 개인 업무 플랫폼입니다.

## HTML 파일로 실행하기 (기본 방식)

루트의 **`모아.html`** 파일을 Chrome 또는 Edge에서 더블클릭해 여세요. 화면·스타일·문서 미리보기 코드를 하나의 HTML에 포함해 서버·설치·인터넷 연결 없이 사용할 수 있습니다. EXE를 만들 필요가 없습니다.

메모, 표, 도형, 구분선, 고정 크기 페이지, 하단 페이지 번호 이동, 자동 저장과 파일 미리보기를 사용할 수 있습니다. 파일 접근 권한을 허용하면 지원 브라우저에서 원본을 다시 읽습니다. 권한을 사용할 수 없는 경우 등록 시점의 사본을 보관하며 화면에 구분해 안내합니다.

**HTML 버전의 범위:** 파일을 클릭하면 브라우저 안의 미리보기가 열립니다. 순수 HTML은 Windows의 한글·Office 기본 연결 프로그램을 직접 실행할 수 없습니다. 기본 프로그램에서 원본을 바로 여는 동작은 아래의 선택적인 데스크톱 방식에서만 지원합니다.

페이지와 파일 연결은 현재 브라우저의 로컬 저장소에 저장됩니다. 같은 브라우저·같은 파일 경로를 유지해 사용하세요. 다른 브라우저, 다른 PC 또는 파일 경로에서 저장 데이터가 공유된다고 보장하지 않습니다. 사이트 데이터를 삭제하면 저장한 작업이 사라집니다. 보안 정책이 적용된 회사 브라우저는 로컬 HTML 또는 파일 접근을 차단할 수 있습니다.

### HTML 수정·재생성 (개발자)

`src/`의 소스를 수정한 뒤 다음 명령으로 `모아.html`을 갱신합니다. 생성된 HTML의 번들 코드를 직접 수정하지 마세요.

```sh
npm ci
npm run build:html
```

실행 사용자에게 Node.js는 필요하지 않습니다. HTML 버전 테스트는 `npm run test:html`입니다. 이 클라우드의 관리 Chromium은 `file://`를 차단하므로, 테스트는 네이티브 기능이나 preload가 없는 Electron Chromium 창에서 **실제 로컬 HTML 파일**을 열어 수행합니다. Linux에서는 X 디스플레이가 필요합니다. Windows의 Chrome/Edge에서의 직접 실행은 별도 확인이 필요합니다.

## 선택 사항: Windows 데스크톱 방식

`release/Moa-0.1.0-Windows.exe` 하나를 PC에 내려받아 더블클릭하세요. 설치 과정이나 Node.js, 터미널은 필요하지 않습니다. Windows x64용 포터블 실행 파일이며 첫 실행 시 내장된 구성요소를 임시 폴더에 자동으로 풀어 실행합니다.

1. **파일 바로가기 추가**를 눌러 내 컴퓨터의 파일을 선택하거나 파일을 보드로 끌어 놓습니다.
2. 보드에 추가한 파일 카드를 클릭하면, 그 **원본 경로**의 파일이 Windows의 기본 연결 프로그램으로 열립니다.
3. 카드의 눈 모양 버튼 또는 마우스 올리기는 미리보기용입니다. 카드 클릭으로 모아 안에서 문서를 편집하지 않습니다.

한글 파일은 PC의 한글 프로그램, Word·Excel·PowerPoint 문서는 해당 기본 연결 프로그램에서 열립니다. 해당 형식을 여는 프로그램이 설치되어 있어야 합니다. 원본 파일의 내용을 모아에 복사하거나 업로드하지 않고 위치만 저장합니다. 원본을 수정하면 다음 미리보기에 최신 내용이 반영됩니다. 원본이 이동·삭제되면 **파일 바로가기 추가**에서 다시 선택하세요. 페이지와 바로가기 설정은 앱의 사용자 데이터 폴더에 보관되며 실행 파일을 종료해도 유지됩니다.

생성된 Windows 실행 파일은 코드 서명되지 않았습니다. Linux 클라우드에서 Windows x64용으로 패키징했으며 Windows에서 직접 실행하는 검증은 별도로 필요합니다. 공용 UI와 실제 경로 등록·파일 읽기·바로가기 열기 요청은 Electron 실행 및 패키징된 Linux 앱에서 검증합니다.

## 소스에서 개발·빌드

Node.js 22.12 이상과 npm이 필요합니다. 프로그램 사용자에게는 필요하지 않습니다.

```sh
npm ci
npm run dev          # 웹 개발
npm run desktop      # 데스크톱 개발
npm run package:win  # Windows 단일 실행 파일 생성
```

Windows 산출물은 `release/Moa-0.1.0-Windows.exe`입니다. 데스크톱의 파일 선택·끌어 놓기 등록은 모두 원본 경로를 저장합니다. 웹 버전은 브라우저 권한에 따라 원본 핸들 또는 사본을 사용하므로 아래의 차이를 참고하세요.

## 기능

- 상단 도구모음: 텍스트, 메모, 표, 사각형, 원, 가로·세로 구분선, 파일 연결
- 블록 선택 후 손잡이로 이동, 모서리로 크기 조절, 색 변경, 복제·삭제
- 표의 셀 편집과 행·열 추가·삭제
- 페이지 추가·이름 변경, 하단 숫자 페이지 이동
- 새 페이지는 현재 모니터의 가용 화면 크기로 고정됩니다. 템플릿 첫 페이지는 1160 × 760입니다. 크기 설정에서 모니터 크기 또는 직접 입력한 크기로 변경할 수 있습니다.
- 화면 크기가 달라져도 페이지 좌표와 배치 유지, 화면에 맞추기·확대·축소·전체 화면
- 페이지, 블록, 파일 연결 정보의 로컬 자동 저장
- 파일 카드에 마우스를 올리면 간단한 미리보기, 클릭하면 큰 미리보기 (데스크톱은 원본 열기)

## 파일 연결과 미리보기

| 형식                        | 미리보기                                                       |
| --------------------------- | -------------------------------------------------------------- |
| 이미지                      | 이미지 표시                                                    |
| PDF                         | 큰 미리보기에서 내장 PDF 뷰어, 호버 시 문서 안내               |
| TXT / MD / CSV / JSON / LOG | 텍스트 (최대 30,000자)                                         |
| Word DOCX                   | 본문 텍스트                                                    |
| Excel XLSX / XLS            | 시트별 데이터, 시트당 최대 60행·15열                           |
| PowerPoint PPTX             | 슬라이드별 텍스트                                              |
| 한글 HWPX                   | 본문 텍스트                                                    |
| HWP / DOC / PPT / 기타      | 미리보기 미지원, 내려받기 또는 데스크톱 연결 프로그램으로 열기 |

Office·HWPX 미리보기는 원본 서식·이미지·차트·수식을 재현하는 뷰어가 아닙니다. 암호화된 문서는 미리보기에서 오류가 날 수 있습니다. 파일 내용은 외부 변환 서버에 업로드하지 않고 로컬에서 처리합니다. 데스크톱 미리보기는 80MB 이하 파일을 지원하며 큰 파일은 원본 연결 프로그램으로 엽니다.

웹의 Chrome/Edge에서 File System Access API가 허용되면 사용자가 선택한 파일 핸들을 저장하고 다시 열 때 원본의 최신 내용을 읽습니다. 브라우저가 다시 권한을 요청할 수 있습니다. 다른 브라우저, 제한된 임베드 화면, 드래그 등록에서는 업로드 시점의 사본을 보관합니다. 웹은 로컬 파일 전체 경로를 얻거나 PC의 기본 프로그램을 직접 실행할 수 없습니다.

페이지와 파일 사본은 현재 브라우저/데스크톱 앱의 IndexedDB에 저장됩니다. 데스크톱 원본 경로 허용 목록은 앱 사용자 데이터 디렉터리에 보관됩니다. 브라우저와 데스크톱의 저장 공간은 서로 다르며 클라우드 동기화·다중 사용자 공동 편집은 제공하지 않습니다. 사이트 데이터를 지우면 작업이 사라지므로 중요한 원본은 별도 보관하세요.

## 검증

```sh
npm test                # 페이지 모델, 경계 처리, 원본 파일 허용 목록
npm run build           # 웹/데스크톱 공용 프로덕션 빌드
npm run test:e2e         # 브라우저 기능 검증
npm run test:desktop     # Electron 실행 및 파일 연결 검증
```

브라우저 테스트는 시스템 Chromium이 있으면 사용하며, 없으면 `npx playwright install chromium`으로 테스트 브라우저를 먼저 설치하세요. Linux의 Electron 테스트는 X 디스플레이가 필요합니다. 클라우드에서는 Xvfb를 사용할 수 있습니다. 데스크톱 테스트는 격리된 임시 프로필을 사용하고, OS 파일 선택과 연결 프로그램 실행을 대체하여 IPC를 통한 실제 경로 등록·파일 읽기·원본 열기 요청을 검증합니다. 사용자 PC의 실제 Office/한글 프로그램 실행까지 자동 검증하지는 않습니다.

## 구조

- `src/main.js`: 한국어 작업 공간 UI와 페이지·블록 편집
- `src/model.js`: 고정 캔버스 모델과 경계 처리
- `src/storage.js`: IndexedDB 및 웹/데스크톱 파일 읽기
- `src/preview.js`: 로컬 문서 미리보기
- `desktop/`: 격리된 Electron 창, 제한된 IPC, 사용자가 선택한 원본 경로 등록

클라우드 개발 환경에서는 `/workspace/work-platform`의 기존 체크아웃을 사용하세요. 별도 Git worktree는 필요하지 않습니다.

## 수정본 전달

사용자 요청에 따라 매 수정본은 `npm run package:html`로 ZIP을 생성합니다. `deliveries/`에 한국 시간의 생성 시각을 포함한 파일이 만들어집니다. ZIP에는 단독 실행용 `모아.html`, `사용방법.txt`, `개발용소스/`가 들어 있습니다. 파일 생성 후 ZIP CRC 및 HTML 일치를 검사합니다. 클라우드 내부 파일 생성과 사용자 PC로의 다운로드는 별개이며, 실제 첨부·내보내기 기능으로 전달이 확인된 경우에만 다운로드 가능하다고 안내합니다.
