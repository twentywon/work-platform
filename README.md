# 코션 · COTION

메모, 표, 도형과 원본 파일 바로가기를 배치하는 개인 업무 보드입니다.

## Windows 10/11에서 실행

1. ZIP 전체를 압축 해제하고 이전 코션 창과 검은 연결 도우미 창을 닫습니다.
2. **코션 실행.vbs**를 더블클릭합니다. 검은 창 없이 전용 HTML 창이 열리며, 코션 창을 닫으면 연결 도우미도 종료됩니다. CMD도 같은 창을 실행합니다. EXE 빌드나 Node.js 설치는 필요하지 않습니다.
시작 전에 공식 SDK DLL 4개의 고정 SHA256을 검사한 뒤 해당 DLL에 한해 다운로드 영역 표시를 해제합니다. Windows의 `0x80131515` DLL 로드 오류를 방지하기 위한 처리입니다. 해제가 실패하면 ZIP 우클릭 → 속성 → **차단 해제** 후 새 폴더에 다시 압축 해제하세요. 시스템 보안 설정과 사용자 문서는 변경하지 않습니다.

3. 설치된 **Microsoft Edge WebView2 Runtime**을 사용합니다. 없거나 오래된 경우 [Microsoft 공식 안내](https://developer.microsoft.com/microsoft-edge/webview2/)에서 설치·업데이트하세요. 공식 SDK DLL과 라이선스·출처·해시는 ZIP의 `webview2/`에 포함합니다.
4. 탐색기 파일을 전용 창에 끌어놓거나 **파일 연결**에서 고르면 원본 경로를 바로 등록합니다. 폴더 연결과 추가 원본 확인 창이 필요하지 않습니다. 카드 클릭은 원본을 Windows 기본 연결 프로그램으로 엽니다. 원본 문서 사본이나 다운로드를 만들지 않습니다.
5. **경로 붙여넣기**도 지원합니다. 원본을 이동·삭제하면 다시 연결하세요.

전용 창은 WebView2 `postMessageWithAdditionalObjects`로 사용자가 직접 드래그하거나 선택한 File의 네이티브 경로를 받습니다. 파일명만으로 경로를 추측하지 않습니다. 일반 브라우저에서는 이 기능이 없으므로 전용 창 사용 안내를 표시합니다. `코션.html`만 열면 별도의 브라우저 미리보기 모드입니다.

**기존 보드 이전:** 전용 창을 켜 둔 채 이전에 쓰던 Chrome·Edge에서 `http://127.0.0.1:17843`을 여세요. 기존 보드의 **백업·복원 → 현재 작업 백업**을 누르고, 새 전용 창에서 **백업 파일 복원**으로 옮깁니다. 두 창은 저장 공간이 다르며 복원은 현재 보드를 바꿉니다. 백업에는 보드·바로가기 경로·보드 미디어 사본이 포함됩니다. 원본 문서는 복사하지 않습니다.

선택 창과 Office 변환은 별도 STA PowerShell 프로세스에서 처리합니다. Office 변환에는 45초 제한을 둡니다. 코션 창이 백그라운드 서버를 소유하고 정상 종료를 요청하며, 실패하면 자신이 시작한 서버만 종료합니다. 시작 오류는 메시지 창으로 알리고 도우미 로그는 `%LOCALAPPDATA%\MoaWeb\helper.log`에 남깁니다.

## 첫 페이지 이미지 미리보기

카드에 마우스를 올리거나 눈 버튼을 누르면 다음 방식으로 미리보기를 표시합니다.

| 형식 | 이미지 생성 방식 |
| --- | --- |
| PDF | 내장 PDF.js로 실제 첫 페이지를 PNG로 렌더링. 큰 창에서는 원본 PDF의 전체 페이지도 볼 수 있습니다. |
| HWP / HWPX | 파일에 저장된 PrvImage 미리보기를 우선 표시합니다. 없으면 설치된 Windows 문서 미리보기 제공자를 시도합니다. |
| Word DOC / DOCX | 연결 도우미에서는 설치된 Word에서 읽기 전용으로 첫 페이지를 PDF로 내보내 렌더링합니다. |
| Excel XLS / XLSX | 연결 도우미에서는 설치된 Excel에서 **첫 워크시트의 첫 인쇄 페이지**를 PDF로 내보냅니다. |
| PowerPoint PPT / PPTX | 연결 도우미에서는 설치된 PowerPoint에서 첫 슬라이드를 PNG로 내보냅니다. |
| 이미지 / GIF | 원본 이미지를 표시합니다. |

미리보기의 출처를 화면에 표시합니다. 저장된 미리보기는 저장 당시 이미지이며, Windows 제공자의 미리보기는 설치된 핸들러에 따라 크기와 내용이 다릅니다. 한글·Office가 설치되어 있어도 암호·손상·보안 정책·미리보기 저장 설정 등에 따라 이미지 생성이 실패할 수 있습니다. 이 경우 이유를 표시하고 가능한 본문 텍스트·표로 전환합니다. 파일 아이콘을 문서 첫 페이지처럼 표시하지 않습니다.

Office 변환은 매크로를 비활성화하고 읽기 전용으로 엽니다. 원본 문서를 저장하거나 수정하지 않습니다. PDF/PNG 파생 이미지는 `%LOCALAPPDATA%\MoaWeb\jobs` 아래의 세션 임시 폴더에 만듭니다. 외부 서버로 문서를 보내지 않으며 정상 종료 시 세션 임시 파일을 정리합니다. 80MB 초과 문서는 원본 프로그램에서 여세요.

## 코션 v0.8 · 제목, 아이콘, 단축키

OFL 라이선스의 Noto Serif KR에서 코션 두 글자만 추출한 명조체 워드마크와 새 아이콘을 사용합니다. Windows 창 아이콘과 AppUserModelID를 지정해 작업표시줄 그룹에 사용합니다. PNG/ICO(16~256px)와 수정 가능한 SVG를 포함합니다. 제목용 글꼴은 HTML에 포함하고 OFL 원문·출처·해시는 ZIP에 동봉합니다. 기존 IndexedDB·원본 경로 저장 위치와 백업 형식은 유지하므로 이전 작업을 그대로 사용합니다.

| 단축키 | 동작 |
| --- | --- |
| Ctrl+C / X / V | 선택한 개체 복사 / 잘라내기 / 붙여넣기. 입력 중에는 일반 텍스트 클립보드 유지 |
| Ctrl+D | 선택 개체 복제 |
| Ctrl+Z / Ctrl+Y 또는 Ctrl+Shift+Z | 편집 취소 / 다시 실행 |
| Ctrl+A / Ctrl+S | 전체 선택 / 즉시 저장 |
| Ctrl+N / Ctrl+O | 새 페이지 / 파일 연결 |
| Ctrl+B / I / U / Shift+X | 굵게 / 기울임 / 밑줄 / 취소선 |
| Ctrl+L / E / R | 텍스트 왼쪽 / 가운데 / 오른쪽 정렬 |
| 방향키 / Shift+방향키 | 1px / 10px 이동. 입력 중에는 커서 이동 유지 |
| Delete / Esc / F2 / Enter | 삭제 / 선택·드래그 취소 / 내용 편집 / 파일 열기 또는 서랍 접기·펼치기 |

개체 복사는 같은 작업 공간의 파일 ID를 참조하며 원본 문서나 미디어 바이트를 클립보드에 복사하지 않습니다. Chrome/Edge 입력 칸의 일반 복사/붙여넣기는 유지합니다. 새 편집을 하면 다시 실행 기록은 초기화되며 취소 기록은 앱 종료·새로고침 시 사라집니다. 시스템 클립보드의 실제 Windows 전달과 작업표시줄 표시 결과는 Windows에서 확인해야 합니다.

제목 텍스트도 높이에 맞춰 여러 줄을 표시하고 정렬합니다. 긴 영문/URL도 상자 안에서 줄바꿈합니다. 개체 정렬은 단일 개체는 페이지 기준, 여러 개체는 선택 영역 기준입니다. 회전만으로 X/Y/너비/높이는 바뀌지 않습니다. 페이지 경계에서 회전된 부분은 보드 밖으로 나올 수 있으며 이동·크기 변경 시에는 경계 보정을 적용합니다.

도형 메뉴에는 사각형/원 외에 둥근 사각형, 삼각형, 마름모, 오각형, 육각형, 별, 화살표, 평행사변형, 말풍선, 하트가 있습니다. 서식 초기화 버튼은 제거했습니다.

## 화면 선명도

전용 창은 WinForms/WebView2 핸들을 만들기 전에 UI 스레드를 Per-Monitor V2 DPI 모드로 설정하고 DPI 자동 배율을 사용합니다. 지원하지 않는 Windows API는 이전 DPI 모드로 전환합니다. 보드는 transform 확대 대신 CSS layout zoom으로 목표 배율에서 텍스트를 다시 그리며, 한글 시스템 글꼴과 더 진한 글자·선 색상을 사용합니다. 아래 **1:1** 버튼은 보드를 100%로, 배율 숫자는 가로폭 맞춤으로 전환합니다. 페이지 좌표와 저장 데이터는 유지합니다. 브라우저 배율/DPR별 좌표·편집·스크롤은 자동 검증하며 Windows 125%/150% 설정과 모니터 간 이동은 Windows에서 확인해야 합니다.

## 선택과 개체 설정

- 보드 여백을 드래그하면 범위와 겹치는 최상위 개체들을 선택합니다. Shift/Ctrl+클릭으로 선택을 추가·해제하고 Ctrl+A로 보드 개체를 모두 선택합니다. 텍스트 입력 중에는 원래 입력 단축키를 유지합니다.
- 선택한 개체의 테두리나 이동 손잡이를 끌면 함께 이동합니다. 닫힌/열린 서랍 위로 끌어 강조 표시가 나타난 곳에 놓으면 여러 개체를 함께 넣습니다. 서랍 안에 서랍은 넣지 않습니다. 범위 선택과 이동 중 보드 가장자리에 다가가면 자동 스크롤하고 Esc로 진행 중 동작을 취소합니다.
- 삽입 도구모음 바로 아래의 한 줄 설정은 가로로 스크롤할 수 있습니다. 텍스트 계열은 개체 전체의 글꼴, 크기, 굵게, 기울임, 밑줄/취소선 동시 적용, 색, 정렬, 줄 간격을 설정합니다. 개체 안에서 선택한 일부 글자만 서식을 바꾸는 방식은 아닙니다.
- 공통 설정: 배경·테두리·불투명도, 위치/크기/회전, 위치 잠금, 앞뒤 순서, 복제/삭제. 여러 개체는 일괄 서식, 정렬, 이동, 서랍 넣기가 가능합니다. 위치 잠금은 이동·크기·회전을 막으며 내용 편집과 삭제는 가능합니다.
- 표 행·열 추가/제거, 도형 종류, 구분선 방향·색·두께, 미디어 contain/cover와 영상 반복/음소거, 파일 표시 이름·열기·미리보기, 체크 완료, 달력 월, 링크 수정, 서랍 이름·접기·꺼내기를 설정할 수 있습니다.
- 삭제 취소는 삭제된 개체만 원래 순서로 복구하고 이후 다른 개체에 쓴 내용은 유지합니다. 삭제 취소 기록은 앱을 종료하거나 새로고침하면 초기화됩니다. 원본 문서와 보드 미디어 파일 저장소를 직접 삭제하지 않습니다.

## 보드 편집

- 페이지 좌표 크기는 고정하고 **가로폭에 맞춰** 표시합니다. 긴 페이지는 세로로 스크롤합니다.
- 텍스트, 메모, 표, 도형, 가로·세로 구분선을 삽입할 수 있습니다. 보드 위 안내 영역은 제거했습니다.
- 개체를 선택하고 손잡이로 이동·크기 조절하면 20px 격자에 맞춥니다. 회전 손잡이는 15도 간격이며 각도 입력·90도 회전도 지원합니다.
- **서랍**을 펼쳐 기존 개체 또는 파일·이미지·GIF·영상·메모·체크를 목록으로 담고 순서를 바꾸거나 보드로 꺼냅니다. 서랍 삭제 시 안의 개체도 보드에서 함께 삭제됩니다. PC 원본 파일은 삭제하지 않습니다. 삭제 취소 버튼 또는 입력 중이 아닐 때 Ctrl+Z로 이번 실행 중 삭제를 되돌릴 수 있습니다. 서랍 안에 서랍은 넣을 수 없습니다.
- 개체의 테두리를 클릭하면 내용 실행 없이 선택합니다.
- **체크박스**에서 할 일과 완료 상태를 저장합니다.
- **더 삽입 → 미디어**에서 이미지·GIF·영상을 보드에 표시합니다. 보드 미디어는 브라우저에 사본으로 저장하며 파일당 100MB까지 지원합니다. MP4(H.264), WebM을 권장합니다.
- **더 삽입 → 인터넷 링크**에서 http/https 링크를 새 탭으로 엽니다.
- **더 삽입 → 달력**에서 날짜별 일정을 기록합니다.
- **더 삽입 → 페이지 링크**에서 다른 보드 페이지로 이동하는 카드를 만듭니다.

## 저장과 연결 상태

작업은 전용 WebView2 프로필의 `http://127.0.0.1:17843` IndexedDB에 자동 저장됩니다. 프로필 위치는 `%LOCALAPPDATA%\MoaWeb\WebView2`입니다. 브라우저별 저장 공간과 다르므로 이전 작업은 백업·복원으로 옮깁니다. 원본 경로는 `%LOCALAPPDATA%\MoaWeb\links.json`에 저장됩니다. 이전 버전의 경로 등록 기록도 유지합니다. 브라우저·PC마다 저장 공간이 다르며 사이트 데이터를 지우면 작업이 사라집니다. HTML 직접 실행의 저장 공간과 연결 도우미 화면의 저장 공간도 서로 다릅니다. 클라우드 동기화는 제공하지 않습니다.

상단 PC 연결 도우미 버튼에서 버전과 연결 상태를 확인합니다. 도우미는 루프백 주소만 사용하고 Host/Origin과 실행마다 만든 토큰을 검사합니다. 등록한 문서 ID만 읽거나 열 수 있으며 실행 파일·스크립트는 등록하지 않습니다. 선택·변환 작업 ID도 허용 목록으로 관리합니다.

## 개발과 ZIP 전달

Node.js 22.12 이상에서 다음 명령을 사용합니다.

```sh
npm ci
npm test
npm run test:e2e
npm run test:html
npm run test:local
npm run package:html
```

`npm run package:html`은 HTML, VBS/CMD/PowerShell 실행 스크립트, Microsoft WebView2 SDK DLL, 한국어 안내와 수정 가능한 소스를 ZIP으로 만듭니다. PDF 렌더러와 워커 코드는 HTML에 포함하므로 실행 PC에서 추가 다운로드하지 않습니다. ZIP CRC와 HTML 일치를 검사하고 GitHub 다운로드 링크로 전달합니다.

브라우저와 실제 PowerShell 서버에서 원본 경로 등록·작업 프로세스 수명·다운로드 없는 열기 요청·첫 페이지 렌더링·저장을 검증합니다. PDF 테스트는 빨간 첫 페이지와 파란 두 번째 페이지를 가진 실제 PDF의 픽셀을 검사합니다. HWP/HWPX 테스트는 저장된 이미지 스트림을 추출합니다. Linux에서는 WebView2 파일 전달 경계를 모의하고 실제 PowerShell 경로 등록·읽기와 연결합니다. Windows WebView2 시작·실제 드래그·기본 프로그램 실행·Office COM은 Windows에서 확인해야 합니다. 관리 Chromium의 file:// 차단으로 HTML 직접 실행 테스트는 브리지 없는 Electron Chromium 창을 사용합니다.

Electron 개발 소스는 desktop/에 유지하며 `npm run desktop`으로 실행합니다. 사용자 요청 없이 EXE를 새로 만들지 않습니다.

SDK 준비 회귀 검증은 `pwsh -NoProfile -File tests/sdk-preparation.ps1`로 실행합니다. 실제 DLL 해시·누락·변조 거부와 로드 전 준비 순서를 검사합니다. Windows에서는 NTFS Zone.Identifier를 실제 생성·해제하며, Linux에서는 Unblock-File 경계만 모의합니다.
