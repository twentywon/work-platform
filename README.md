# 모아 · MOA

메모, 표, 도형과 원본 파일 바로가기를 배치하는 개인 업무 보드입니다.

## Windows 10/11에서 실행

1. ZIP을 압축 해제합니다. 업데이트할 때는 이전 연결 도우미 창을 먼저 닫습니다.
2. **모아 실행.cmd**를 실행하면 브라우저가 열립니다. 함께 뜨는 연결 도우미 창은 열어 두세요. EXE나 Node.js 설치는 필요하지 않습니다.
3. **파일 연결**을 누르고 Windows 선택 창에서 원본 파일을 고릅니다. **폴더 사전 지정은 필요하지 않습니다.**
4. 파일 카드를 누르면 PC의 기본 연결 프로그램으로 그 원본 경로를 엽니다. 원본 문서를 사본으로 저장하거나 다운로드하지 않습니다.
5. 선택 창이 보이지 않으면 Alt+Tab에서 ‘모아’를 확인하거나 **경로 붙여넣기**를 사용하세요. 탐색기에서 파일을 Shift+우클릭 → 경로로 복사한 결과를 붙여넣으면 됩니다.

브라우저에 파일을 끌어 놓으면 전체 경로가 숨겨지므로, Windows 선택 창에서 해당 원본 파일을 한 번 확인합니다. 임의의 폴더를 검색하거나 파일 이름만으로 원본 위치를 추측하지 않습니다. Electron 개발판에서는 네이티브 드래그 경로를 사용할 수 있습니다.

Windows 선택 창과 문서 변환은 각각 별도의 STA PowerShell 프로세스에서 실행합니다. 선택 창이 열려 있거나 Office가 미리보기를 만들고 있어도 연결 도우미는 요청에 응답할 수 있습니다. 선택을 취소할 수 있고 문서 변환은 45초 제한을 둡니다. 원본 파일이 이동·삭제되면 다시 연결하세요.

`모아.html`만 직접 열면 브라우저 미리보기 모드입니다. PC 원본을 기본 프로그램으로 여는 기능은 `모아 실행.cmd`가 필요합니다. 지원 브라우저에서는 원본 파일 핸들을 저장하고, 그 외에는 파일 사본을 보관한다고 표시합니다.

## 첫 페이지 이미지 미리보기

카드에 마우스를 올리거나 눈 버튼을 누르면 다음 방식으로 미리보기를 표시합니다.

| 형식 | 이미지 생성 방식 |
| --- | --- |
| PDF | 내장 PDF.js로 실제 첫 페이지를 PNG로 렌더링. 큰 창에서는 원본 PDF의 전체 페이지도 볼 수 있습니다. |
| HWP / HWPX | 파일에 저장된 PrvImage 미리보기를 우선 표시합니다. 없으면 설치된 Windows 문서 미리보기 제공자를 시도합니다. |
| Word DOC / DOCX | 연결 도우미에서는 설치된 Word에서 읽기 전용으로 첫 페이지를 PDF로 내보내 렌더링합니다. |
| Excel XLS / XLSX | 연결 도우미에서는 설치된 Excel에서 **첫 워크시트의 첫 인쇄 페이지**를 PDF로 내보냅니다. |
| PowerPoint PPT / PPTX | 연결 도우미에서는 설치된 PowerPoint에서 첫 슬라이드를 PNG로 내보냅니다. |
| 이미지 / GIF | 원본 이미지를 표시합니다. |

미리보기의 출처를 화면에 표시합니다. 저장된 미리보기는 저장 당시 이미지이며, Windows 제공자의 미리보기는 설치된 핸들러에 따라 크기와 내용이 다릅니다. 한글·Office가 설치되어 있어도 암호·손상·보안 정책·미리보기 저장 설정 등에 따라 이미지 생성이 실패할 수 있습니다. 이 경우 이유를 표시하고 가능한 본문 텍스트·표로 전환합니다. 파일 아이콘을 문서 첫 페이지처럼 표시하지 않습니다.

Office 변환은 매크로를 비활성화하고 읽기 전용으로 엽니다. 원본 문서를 저장하거나 수정하지 않습니다. PDF/PNG 파생 이미지는 `%LOCALAPPDATA%\MoaWeb\jobs` 아래의 세션 임시 폴더에 만듭니다. 외부 서버로 문서를 보내지 않으며 정상 종료 시 세션 임시 파일을 정리합니다. 80MB 초과 문서는 원본 프로그램에서 여세요.

## 보드 편집

- 페이지 좌표 크기는 고정하고 **가로폭에 맞춰** 표시합니다. 긴 페이지는 세로로 스크롤합니다.
- 텍스트, 메모, 표, 도형, 가로·세로 구분선을 삽입할 수 있습니다. 보드 위 안내 영역은 제거했습니다.
- 개체를 선택하고 손잡이로 이동·크기 조절하면 20px 격자에 맞춥니다. 회전 손잡이는 15도 간격이며 각도 입력·90도 회전도 지원합니다.
- **체크박스**에서 할 일과 완료 상태를 저장합니다.
- **더 삽입 → 미디어**에서 이미지·GIF·영상을 보드에 표시합니다. 보드 미디어는 브라우저에 사본으로 저장하며 파일당 100MB까지 지원합니다. MP4(H.264), WebM을 권장합니다.
- **더 삽입 → 인터넷 링크**에서 http/https 링크를 새 탭으로 엽니다.
- **더 삽입 → 달력**에서 날짜별 일정을 기록합니다.
- **더 삽입 → 페이지 링크**에서 다른 보드 페이지로 이동하는 카드를 만듭니다.

## 저장과 연결 상태

작업은 같은 브라우저의 `http://127.0.0.1:17843` IndexedDB에 자동 저장됩니다. 원본 경로는 `%LOCALAPPDATA%\MoaWeb\links.json`에 저장됩니다. 이전 버전의 경로 등록 기록도 유지합니다. 브라우저·PC마다 저장 공간이 다르며 사이트 데이터를 지우면 작업이 사라집니다. HTML 직접 실행의 저장 공간과 연결 도우미 화면의 저장 공간도 서로 다릅니다. 클라우드 동기화는 제공하지 않습니다.

상단 PC 연결 도우미 버튼에서 버전과 연결 상태를 확인합니다. 도우미는 루프백 주소만 사용하고 Host/Origin과 실행마다 만든 토큰을 검사합니다. 등록한 문서 ID만 읽거나 열 수 있으며 실행 파일·스크립트는 등록하지 않습니다. 선택·변환 작업 ID도 허용 목록으로 관리합니다.

## 개발과 ZIP 전달

Node.js 22.12 이상에서 다음 명령을 사용합니다.

```sh
npm ci
npm test
npm run test:e2e
npm run test:html
npm run test:local
npm run package:html
```

`npm run package:html`은 HTML, CMD/PowerShell 도우미 두 파일, 한국어 안내와 수정 가능한 소스를 ZIP으로 만듭니다. PDF 렌더러와 워커 코드는 HTML에 포함하므로 실행 PC에서 추가 다운로드하지 않습니다. ZIP CRC와 HTML 일치를 검사하고 GitHub 다운로드 링크로 전달합니다.

브라우저와 실제 PowerShell 서버에서 원본 경로 등록·작업 프로세스 수명·다운로드 없는 열기 요청·첫 페이지 렌더링·저장을 검증합니다. PDF 테스트는 빨간 첫 페이지와 파란 두 번째 페이지를 가진 실제 PDF의 픽셀을 검사합니다. HWP/HWPX 테스트는 저장된 이미지 스트림을 추출합니다. Linux에서 Windows 선택 창 및 Office COM 실행을 직접 검증할 수 없으므로 그 부분은 Windows에서 확인해야 합니다. 관리 Chromium의 file:// 차단으로 HTML 직접 실행 테스트는 브리지 없는 Electron Chromium 창을 사용합니다.

Electron 개발 소스는 desktop/에 유지하며 `npm run desktop`으로 실행합니다. 사용자 요청 없이 EXE를 새로 만들지 않습니다.
